# T-001 - Engine de simulare cu pasi discreti
Owner: claude | Fisiere permise: sim/core/engine.py, tests/test_engine.py

## Scop
Bucla de simulare. Engine-ul NU contine algoritmi. Primeste Planner si Allocator
prin constructor, ca sa putem schimba algoritmul fara sa atingem engine-ul.

## API cerut
class Simulation:
    def __init__(self, grid, robots, tasks, planner, allocator, max_ticks=10_000)
    def step(self) -> None      # un singur tick
    def run(self) -> Metrics

## Ordinea stricta intr-un tick t
1. Task-urile cu released_at <= t si neasignate intra in coada `pending`.
2. allocator.assign(roboti_liberi, pending, grid, t). Setezi task_id si assigned_to.
3. Pentru fiecare robot cu task si `path` gol:
   planner.plan(grid, robot.pos, tinta), unde tinta = task.pickup daca carrying
   is None, altfel task.dropoff.
   Daca planner-ul intoarce lista vida: robotul ramane pe loc si task-ul se
   dezasigneaza la finalul tick-ului.
4. Fiecare robot avanseaza EXACT o celula (primul element din path, care se consuma).
5. Detectie coliziuni: doi roboti in aceeasi celula DUPA mutare, SAU schimb de
   pozitii intre doi roboti adiacenti. collisions += 1 pentru fiecare pereche.
   NU rezolvi coliziunea in engine - doar o contorizezi. Rezolvarea e T-004.
6. Robot pe task.pickup fara marfa: carrying = task.id, picked_at = t, path se goleste.
   Robot pe task.dropoff cu marfa: carrying = None, completed_at = t, robotul devine liber.
7. t += 1.

## Deadlock
Daca 50 de tick-uri consecutive niciun robot nu si-a schimbat pozitia si mai
exista task-uri necompletate: deadlocks += 1 si run() se opreste.

## Metrics
Completezi toate campurile. throughput = tasks_done / max(ticks, 1).
Mediile se calculeaza doar pe task-urile care au valorile respective setate.

## Determinism
Acelasi seed + aceeasi configuratie => Metrics identice. Fara iterare pe set/dict
in logica de decizie. Sorteaza explicit dupa id.

## Teste (tests/test_engine.py)
Folosesti ManhattanPlanner si NearestAllocator din sim.baseline.
- Grid 5x5 fara rafturi, 1 robot, 1 task: tasks_done == 1, makespan > 0.
- Zero task-uri: run() se termina imediat, tasks_done == 0, fara exceptii.
- Doi roboti care trec frontal unul prin altul: collisions >= 1.
- Rulare dubla cu aceeasi configuratie: Metrics egale.
- Robot blocat complet de WALL cu un task activ: deadlocks == 1.
- make_warehouse(20, 20) cu 10 roboti si 30 task-uri: ruleaza fara exceptii.
