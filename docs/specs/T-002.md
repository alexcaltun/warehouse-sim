# T-002 - A* pe grid cu obstacole statice
Owner: agy | Fisiere permise: sim/planner/astar.py, tests/test_astar.py

## Scop
Implementare A* care respecta protocolul Planner din sim/core/types.py.
Inlocuieste ManhattanPlanner, care ignora obstacolele.

## API cerut
class AStarPlanner:
    name = "astar"
    def plan(self, grid, start, goal, reservations=None, t=0) -> list[Pos]

- Miscare in 4 directii, cost 1 per pas.
- Euristica: distanta Manhattan.
- Rezultatul EXCLUDE pozitia de start si INCLUDE goal.
- Daca nu exista drum: lista vida. NU arunca exceptie.
- start == goal: lista vida.
- Parametrul `reservations` se IGNORA in acest task (e pentru T-004). Il accepti
  in semnatura si atat.

## Determinism
Doua apeluri identice => acelasi drum, bit cu bit. La costuri egale in heap,
departajezi dupa (f, h, pozitie) - niciodata dupa ordinea de inserare.
Foloseste grid.neighbors(), care are deja ordine fixa.

## Performanta
Grid 100x100 cu rafturi: un apel sub 50 ms. Foloseste heapq si un set de vizitate.
Fara librarii externe, doar stdlib.

## Teste (tests/test_astar.py)
- Grid 5x5 gol, (0,0) -> (4,4): len(path) == 8, path[-1] == (4,4), (0,0) not in path.
- Perete vertical de SHELF cu o singura breasa: drumul trece prin breasa.
- Goal complet inconjurat de SHELF: path == [].
- start == goal: path == [].
- Fiecare pas consecutiv din path e adiacent (distanta Manhattan 1).
- Fiecare celula din path e grid.passable().
- Pe make_warehouse(30,30): A* da drum mai scurt sau egal fata de orice drum valid
  gasit manual, si mai scurt decat ManhattanPlanner cand acesta trece prin rafturi.
- Determinism: doua apeluri identice dau liste egale.
