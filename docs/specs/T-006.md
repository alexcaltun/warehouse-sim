# T-006 - Eliberarea robotilor parcati (evacuare locala)
Owner: claude | Fisiere permise: sim/core/engine.py, sim/core/types.py,
tests/test_collisions.py, tests/test_evacuation.py

## Problema, masurata
Cu use_reservations=True, coliziunile ajung la 0 pe toate configuratiile - mecanismul
de rezervari functioneaza. Dar livrarile se prabusesc la 10-12 din 30 si apare deadlock
pe fiecare seed testat.

Cauza NU e latimea culoarelor: masurat cu aisle=1, 2 si 3, rezultatul ramane 10, 4 si 11
din 30. Cauza e ca un robot liber ramane parcat definitiv pe celula unde a livrat si o
rezerva permanent. Alt robot care are nevoie de acea celula nu ajunge niciodata acolo.

## Ce implementezi
Un robot liber (task_id is None) care blocheaza drumul altcuiva se DA LA O PARTE.

In engine, cand un robot cu task esueaza sa gaseasca drum si celula-problema e ocupata
de un robot liber:
1. Robotul liber primeste un drum catre cea mai apropiata celula penetrabila nerezervata
   care nu e nici pickup, nici dropoff al vreunui task neterminat.
2. Se replanifica robotul cu task, in acelasi tick, dupa ce evacuarea e inregistrata.
3. Daca nu exista nicio celula de evacuare, robotul cu task asteapta - nu e deadlock,
   doar congestie temporara.

Adaugi `Metrics.evacuations: int = 0` in types.py (acum e permis) si numeri de cate ori
s-a declansat mecanismul. E o metrica buna pentru lucrare: cat de des congestioneaza
depozitul.

Completezi si `max_wait` in Simulation.metrics(), dupa avg_wait:
  max_wait=max(waits, default=0),
si scoti marcajul xfail de pe test_max_wait_at_least_avg_wait.

## Terminare garantata
Bucla de evacuare trebuie sa se termine. Un robot poate fi evacuat cel mult o data pe tick;
tii evidenta intr-un set resetat la inceputul fiecarui tick.

## Criteriu de acceptare - acesta este testul care conteaza
make_warehouse(20,20), 10 roboti, 30 task-uri, PrioritizedPlanner(AStarPlanner()),
NearestAllocator(), use_reservations=True, pe seed-urile 1, 3 si 7:
- tasks_done == 30 pe toate trei
- collisions == 0 pe toate trei
- deadlocks == 0 pe toate trei
- makespan >= cel fara rezervari (costul sigurantei, verificat explicit)

Scoti xfail-ul de pe cele trei teste marcate la T-004 si trebuie sa treaca.

## Teste suplimentare (tests/test_evacuation.py)
- Coridor de latime 1, un robot liber parcat la mijloc, altul cu task care trebuie sa treaca:
  robotul liber se muta, celalalt ajunge, collisions == 0.
- Robot liber parcat pe dropoff-ul unui task activ: se muta inainte ca celalalt sa ajunga.
- Grid complet plin, nicio celula libera de evacuare: fara exceptii, fara bucla infinita.
- Determinism: doua rulari identice dau Metrics egale, evacuations inclus.
- Fara rezervari (use_reservations=False): zero evacuari, comportament neschimbat,
  toate testele din test_engine.py trec.

## Definition of done
pytest -q trece complet, ZERO xfail ramase. Nu ai atins world.py, baseline.py,
astar.py, prioritized.py sau fisierele lui agy.
